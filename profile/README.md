## Tech stack and common tools

Developers working with FIN-DSP are expected to be familiar with:

* JUCE, the producer framework for modular and cross-platform audio applications
* Cabbage, for VST and audio plugin development
* CMake and GlibC, standard build systems for Linux audio software

### Core Linux libraries and dependencies

* ALSA and JACK (audio input and output)
* libsndfile, PortAudio, FFTW, RtAudio (signal processing)
* GTK or Qt (optional GUI modules)
* GCC and Clang, Git, Make, Python scripting (for build automation)
* Optional and research-oriented: OpenGL, Vulkan, or other graphics libraries for UI visualization and audio-reactive displays

## Active projects

### Tutka 1.1.3, modern CTP-EOS, Debian and Arch, Linux MIDI tracker

Revitalized for 2026, Tutka is a lightweight, MIDI-only tracker sequencer designed for GNU and Linux (Debian 13 and up tested, Mac OS X source available). With full support for Tutka and OctaMED song formats, plus standard MIDI, it seamlessly integrates with hardware synths or software via ALSA, JACK, and PipeWire. This release adds a ready-to-run binary, modern Qt5 compatibility, and streamlined build paths, making it the fastest way to sequence retro-inspired music on modern systems.

Repo: https://github.com/fin-dsp/tutka

### PlayerPRO Linux port

PlayerPRO is a classic Mac tracker, famously used in Aphex Twin's Vordhosbn track.

We are actively working to bring PlayerPRO to Linux, with the following goals:

* Fully working Linux port of the original PlayerPRO tracker
* New Makefile for Linux compilation
* Full Linux compatibility with all original PlayerPRO plugins
* Possible inclusion of SDK or resources for developers to create additional plugins

Aphex Twin, Vordhosbn (PlayerPRO track): https://www.youtube.com/watch?v=pAZo7x83it4

Linux support has been added, but the makefile is bare-bones and plug-ins are currently not being built. This project exists for extending these purposes and goals.
